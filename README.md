# Rehabify website

Marketing site for Rehabify, a physical medicine and rehabilitation practice
in Bengaluru with video consultations across India.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | local dev server |
| `npm run build` | production build with content and schema checks |
| `npm run start` | serve the production build |
| `npm run lint` | lint the codebase |
| `npm run typecheck` | TypeScript checking |
| `npm run format:check` | formatting check |
