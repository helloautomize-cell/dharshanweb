# Rehabify website

Marketing site for Rehabify, a physical medicine and rehabilitation practice
in Bengaluru with video consultations across India.

## Commands

| Command                                       | Purpose                                       |
| --------------------------------------------- | --------------------------------------------- |
| `npm run dev`                                 | local dev server                              |
| `npm run build`                               | production build with content and leak checks |
| `npm run start`                               | serve the production build                    |
| `npm test`                                    | Playwright suite                              |
| `npm run lint` / `typecheck` / `format:check` | code quality gates                            |
| `npm run images` / `test:images`              | image pipeline and verification               |
| `npm run launch-check`                        | pre-launch blocker report                     |
